## 1. Goal and constraints
- Prop: SGB (Sarmaye Gozare Bartar) Plan A, $1,000 account, Phase 1 target +8% (30 days), Phase 2 +4%; min 5 trading days. Symbol XAUUSD.X on MT5, 1:100.
- Mode: **signal-only**; Amir executes manually (trading EAs/VPS banned; money-management EA allowed).
- Risk: SL cap **$8 at 0.01 lot** (0.01 lot ≈ $1 per $1 move, assuming 100 oz contract — unconfirmed by SGB). Lot = floor(risk$/((SL+spread+commission)×100)) to 0.01.
- Rules: concurrent open risk ≤ 3% of balance; daily loss 5% of start-of-day balance (reset 00:00 server/UTC = 03:30 Tehran); max loss 12% static (equity floor $880, balance and equity both checked); profitable trades held <30 s may contribute at most 20% of phase target ($16) → hold winners ≥30 s.
- Goal: **≥3 profitable signals/day as a MINIMUM (not a cap)**. Overlapping same-side signals deduped only for concurrent-risk reasons.

## 2. Data

## 3. Engine
- Orders are generated by strategies from **closed bars only**; arm time = close of signal bar; fills start on the next M1 bar.
- Fills: limit requires price to trade through (long: low ≤ limit − spread); stop fills at max(stop, open) (gap-through → worse open); market at next open + spread + slip. Fills that open beyond SL or TP are skipped.
- Intrabar: **worst case** — if SL and TP both touched in the same M1 bar, SL wins. Min-hold (30 s modelled as 1 M1 bar where used) defers exits; SL priority.
- Costs: `strict` spread 0.35 + slip 0.10 per side + commission $7/lot round turn; `cheap` 0.20/0.05 used as sensitivity only. SL distance for the cap includes spread.
- Split: IS = first 70% of M1 bars, OOS = last 30% (cut ≈ **2026-07-02**). Variant/filter chosen on IS only, judged on OOS.
- Walk-forward: 40% warm-up, then 4 expanding folds; WF+ = fraction of folds with positive R.
- Monte Carlo: 5,000 bootstrap sims of OOS R-multiples under SGB daily/max DD, 2-loss circuit breaker, pass prob at 0.5% risk. (Note: `run_mc` default target=0.10 — reviewers please check whether 0.08 was passed for Phase 1.)
- Sanity: shift entries 15/60 min and random-side entries; a real edge should collapse under shift/random.
- Circuit breaker: halt day after 2 consecutive losses or −1% day.
- Verdict (`verdict_from`): DROP if OOS n<20, R≤0, PF<1.05, DD>25% or WF+<0.5. KEEP if R≥0.15, PF≥1.2, WF+≥0.75, MC≥0.25. Else MAYBE. Later stages add `robust` = IS_R>0 and OOS_R>0; `promote` gates. About 5 variants per family with family-level multiple-testing awareness.

def _fill_price(side: str, kind: OrderKind, order_price: float, bar_open: float,
                spread: float, slip: float) -> float:
    """Fill price with gap-through: if bar opens through the order, fill at worse open."""
    if kind == "limit":
        # buy limit: fill at min(limit, open) + slip (gap-down through limit → open)
        if side == "long":
            px = min(order_price, bar_open)
            return px + slip
        # sell limit: fill at max(limit, open) - slip
        px = max(order_price, bar_open)
        return px - slip
    if kind == "stop":
        # buy stop: if open gaps above stop → fill at open; else at stop

def walk_forward_folds(m1, n_folds=4):
    """Expanding IS → next OOS slice. Returns list of (is_df, oos_df, name)."""
    times = m1.index
    n = len(times)
    # first 40% warm IS, then 4 equal OOS chunks of remaining 60%
    warm = int(n * 0.40)
    rest = n - warm
    fold_sz = rest // n_folds
    folds = []
    for k in range(n_folds):
        oos0 = warm + k * fold_sz
        oos1 = warm + (k + 1) * fold_sz if k < n_folds - 1 else n
        is_df = m1.iloc[:oos0]
        oos_df = m1.iloc[oos0:oos1]
        folds.append((is_df, oos_df, f"WF{k+1}"))
    return folds

## 4. Bugs found and fixed (all results in this brief are post-fix)
1. **Same-bar fills** — exits could be evaluated optimistically on the fill bar; now worst-case SL-first on the fill bar, same-bar % reported per setup (e.g. AMD ≈45% same-bar SL).
2. **Gap-through** — stop/limit filled at the level even when the bar opened beyond it (≈41% of ProBTB fills, ~$2.94 optimistic). Now fills at the worse open.
3. **M15 leak** — `not_extended` filter used the still-forming M15 bar (and pre-resampled M1 beyond arm time); ≈99% of ProBTB signals affected. Now last-closed M15 only.
4. **SP2L P-gap waiver** — body >1.5×ATR set `has_fvg=True` with no gap (≈53% of accepted spikes). Removed.
5. **MicroMAP TP** — TP computed from stop price while order filled at market close. Fixed to fill price.
6. **`_scan_reentry864` lookahead** — NDS 86.4% re-entry used a later pivot / new Flag before it was confirmed. Now: leg1 = earliest opposite pivot confirmed after primary; new Flag must be confirmed before arm; TP capped at RR.
Effect: prior ProBTB KEEP (n133 PF1.32 MC99%) → n92 PF0.97 DROP; prior AMD KEEP → n19 DROP; NDS r864 no longer promotable.
